# Contributing

Thanks for contributing to Pocket Uplift.

## Workflow
- Create a feature branch from `develop`.
- Use conventional commits: feat:, docs:, chore:.
- Open a PR into `develop`.

## Quality
- Keep changes focused and small.
- Update docs when behavior changes.
- Add tests if you introduce logic that can be tested.

## Data and Evidence
- Place supporting evidence in `docs/evidence/`.
- Do not commit sensitive personal data.
